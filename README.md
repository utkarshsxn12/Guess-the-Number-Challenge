# 🎯 Guess The Number – Interactive Web Game

An engaging and visually rich **Guess The Number** game built using **HTML, CSS, and JavaScript**.  
The game challenges players to guess a randomly generated number within limited time and attempts, making it fun, competitive, and addictive 🚀

---

## 🎮 Game Features 

✨ **Interactive Gameplay**
- Guess the hidden number within a defined range
- Real-time hints: **Too High 📉 / Too Low 📈**
- Limited attempts and countdown timer for added challenge

🎚 **Difficulty Levels**
- 🟢 **Easy**
- 🟡 **Medium**
- 🔴 **Hard**

Each difficulty dynamically changes:
- Number range  
- Allowed attempts  
- Time limit  

🏆 **High Score System**
- Score calculated using remaining attempts and remaining time
- High scores saved using **localStorage**
- Separate high scores for each difficulty
- Scores persist even after browser refresh

🎉 **Win / Lose Experience**
- Celebration modal on winning
- Confetti & firework animations
- Game-over screen with final stats

🌗 **Dark / Light Mode**
- Theme toggle for better user experience
- Smooth UI transitions

📱 **Fully Responsive Design**
- Optimized for mobile, tablet, and desktop
- Touch-friendly buttons and inputs
- Clean and adaptive layout

---

## 🛠 Tech Stack

- **HTML5** – Structure  
- **CSS3** – Styling, animations & responsiveness  
- **JavaScript (ES6)** – Game logic & interactivity  
- **localStorage** – Persistent high score storage  

No external libraries used.

---

## 🚀 How to Play

1. Select a difficulty level
2. Start guessing the number
3. Use hints to refine your guess
4. Beat the timer and attempts  are limited
5. Try to set a new high score 🏆
